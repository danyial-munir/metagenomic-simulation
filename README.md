## What this project is about

A microbiome sample is a vector of **counts of sequencing reads** assigned to bacterial taxa. Such data are
**compositional** (only relative amounts are observed), **sparse** (most taxa are absent in most samples) and
**overdispersed** (more variable between samples than a simple multinomial allows). The project builds statistical models
that can *generate* realistic data of this kind, checks how realistic they are, and then uses the best model to run a
**power study**: if a seasonal or climatic driver changed some taxa by a known amount, could standard tools detect it?

The real dataset has **no time dimension** (each subject was sampled once), so the seasonal driver is **imposed by
simulation**. The study answers *"what would we be able to detect if…"*, **not** *"what is the seasonality of
belly-button bacteria"*.

### Research questions

| | Question |
|---|---|
| **RQ1 – modelling** | Which generative model for compositional count data best reproduces the real skin microbiome (sparsity, overdispersion, diversity, between-sample dissimilarity)? How do covariates (age, sex, washing frequency, navel type) enter it? |
| **RQ2 – validation** | How closely does data simulated from the fitted model match the real data, and with what uncertainty (bootstrap)? |
| **RQ3 – seasonal scenario** | If a seasonal driver changes the abundance of some taxa by effect size *A*, how large must *A* be, and how many samples *n* are needed, before standard tools detect it? |

### Deliverables

1. Literature review (about 4–6 pages, verified references only) → `literature/`
2. Notebooks with the whole analysis (commented, fixed seed, run top to bottom) → `notebooks/`
3. Report (about 15–25 pages) → `report/`
4. Concept sheet for the oral defence → [concept_sheet.md](concept_sheet.md)

Evaluation is an oral discussion with two professors, who judge the work **and** the understanding of the underlying
concepts. For that reason the project prefers clear, standard methods and documents the reasoning behind each choice.

## The data

Two files in `data/raw/` (never modified):

| File | Content |
|---|---|
| `taxonomy.csv` | taxa in rows, 273 samples in columns; 7 taxonomy columns (`Kingdom … Genus`, `Family_Genus`) |
| `environment.csv` | one row per subject (273): ethnicity, gender, age, belly-button washing frequency, navel type (innie/outie), location, … |

**Provenance (unverified):** the data are probably from the belly-button microbiome study (Hulcr et al., *A jungle in
there*, PLoS ONE 2012). However that study, as far as I recall, had about 60 participants, whereas this file has 273, so the
exact origin and the correct citation must be confirmed in the literature step.

### Data audit: what was found (Phase 0)

| Quirk | Finding | Handling |
|---|---|---|
| Decimal commas, quoted | values like `"0,003"` | parsed to floats |
| Trailing junk | the real table is **649 taxa × 273 samples** (file lines 2–650). After it: a richness row, a repeated header, a row of taxon names, a sparse row of 18 decimals, a stray note | cut at the first row with an empty Kingdom cell; junk kept only as audit evidence |
| Column sums "≈ 31" | the junk integer row is the per-sample **richness**; including it in the sum explains the odd 31 | excluded |
| What the numbers are | **fractions of 1000 reads**: every value × 1000 is an integer, smallest value 0.001, `Reads = 1000` | the data are rarefied counts, so exact integer counts are recovered |
| Missing mass | 48 samples sum to < 0.99, 7 to < 0.8, minimum 0.28 | explicit **`Unassigned`** category = 1000 − assigned, so every sample is a full multinomial of 1000 reads |
| Sparsity | 92.9 % zeros | prevalence filter (below) |
| Unresolved taxonomy | ranks `Other` or empty `x__` = unresolved; 204 of 649 rows have no genus; 120 duplicate `Family_Genus` keys | each row labelled by its deepest resolved rank; equal labels summed → 585 labels |
| Metadata mess | `Innie`/`innie`/`Innie `, `None`/`none`, comma decimals in `Wash_Freq`, `Unknown`, unusable ZIP fields | standardised; `Unknown` → missing, **no imputation**; fully logged in `data/processed/decision_table_env.csv` |

**Covariate missingness:** `Wash_Freq` is missing for 42.5 % of subjects (as a block, not at random); navel type 13 %,
ethnicity 12.5 %, age 10 %, gender 3 %. Only 132 subjects are complete on age, gender, wash frequency and navel type.

**Analysis matrix:** taxa present in at least **10 %** of samples (112 taxa) + `Other` + `Unassigned` = 114 categories; every
row sums to 1000. The threshold was fixed before modelling and its sensitivity (2 %–30 %) is tabulated in
`data/processed/filter_sensitivity.csv`.

## Methods

### Phase 0 – Data audit and preparation (done)
Parse, join, clean, standardise, aggregate to the deepest resolved taxonomic rank, filter by prevalence; produce a tidy
counts matrix and metadata table with a decision table (decision, reason, rows affected).

### Phase 1 – Exploratory analysis (done)
Sparsity, prevalence vs mean abundance, rank-abundance, **Taylor's law** (mean–variance per taxon), alpha diversity
(richness, Shannon, Simpson), beta diversity (**Bray–Curtis** and **Aitchison**), PCoA coloured by covariates, exploratory
PERMANOVA with Benjamini–Hochberg correction, pseudocount sensitivity, and a note on compositional data.

### Phase 2 – Generative models (done)
Increasing complexity, fitted by maximum likelihood and compared by held-out log-likelihood (5-fold CV), AIC/BIC where valid,
and a likelihood-ratio test for M1 vs M2. Parameter uncertainty by bootstrap over samples. Models are compared on the
**20 most abundant taxa + `Other` + `Unassigned` (D = 22)**: the logistic-normal likelihood needs a Laplace approximation,
which is accurate at D = 22 but not at all 114 categories (checked against importance sampling). M0 and M1 are also compared at
full resolution.

| Model | Idea |
|---|---|
| **M0** multinomial | one common probability vector for all samples; the baseline, expected to fail on overdispersion |
| **M1** Dirichlet-multinomial | probabilities vary between samples via a Dirichlet; captures overdispersion |
| **M2** DM / Dirichlet regression | covariates (age, sex, washing, navel type) shift the mean composition; top K taxa + `Other` |
| **M3** logistic-normal multinomial | Gaussian on additive log-ratios with a shrunk or low-rank covariance; allows taxon–taxon correlation |
| M4 zero-inflated LNM | added in Phase 3 because M3 makes too few zeros; structural absence per taxon, calibrated by method of moments |

### Phase 3 – Validation of the simulations (planned)
Simulate datasets with the real design from each model and compare with the real data on sparsity, richness and Shannon
distributions, per-taxon prevalence and mean–variance, the Bray–Curtis distribution and PCoA overlay. Uncertainty by
**parametric bootstrap** and **non-parametric bootstrap over samples**; distances between distributions by KS and
Wasserstein; **PERMANOVA of real vs simulated** (a good simulator is hard to tell apart). The final model is chosen with a
written argument.

### Phase 4 – Seasonal scenario / power study (done)
Add the driver `s(t) = cos(2π(month − φ)/12)` (optionally a simulated temperature covariate), perturb the log-ratio abundance
of *K* taxa by amplitude *A*, and vary *A*, sample size *n*, *K*, sequencing depth and baseline overdispersion.
Detection tools: PERMANOVA (Bray–Curtis and Aitchison) with season or month, and per-taxon **cosinor regression** on CLR
with Benjamini–Hochberg FDR control. Outputs: **type I error at A = 0 (should be about 5 %)**, power curves with confidence
bands, minimum detectable effect, power vs *n*, and a power heatmap over (*A*, *n*), with a few hundred replicates per grid
point (justified by the Monte Carlo standard error), a negative control (shuffled labels) and a sensitivity analysis. **The
analysis plan is written down and frozen before any power result is inspected.**

## Key results so far

All numbers are produced by the notebooks (`data/processed/eda_summary.csv`).

- **The data are strongly overdispersed.** Taylor's law slope is **b = 1.84** (bootstrap 95 % CI 1.82–1.89); a common-probability
  multinomial predicts slope 1. Every taxon has more than twice the multinomial variance, with a median of about 22×. A plain
  multinomial (M0) is therefore expected to fail.
- **Dominance:** *Corynebacterium* has a mean relative abundance of 23 %, a Staphylococcaceae bin 19.5 %; the top 10 taxa carry 66 %
  of reads; the median sample has 42 % of its reads in a single taxon.
- **Diversity:** median richness 30, median Shannon 1.91, median Simpson 0.75, median Bray–Curtis between samples 0.79.
- **Covariates explain little.** In PERMANOVA they account for about 0.4–3 % of the distance variance; age group and current state
  (`In_NC`) are the strongest, wash frequency shows nothing. Richness falls with age (Spearman −0.23).
- **Richness caveat:** richness correlates with the number of assigned reads (Spearman −0.69), so it is reported with a warning;
  Shannon and Simpson are less sensitive to rare taxa.
- **Distance choice:** the Aitchison distance is stable across pseudocounts 0.1–2 (pairwise Spearman correlation ≥ 0.89).

**Phase 2 – models** (`data/processed/model_comparison.csv`, D = 22 categories):

| Model | Held-out log-likelihood per sample (5-fold CV) | Difference vs M1 |
|---|---|---|
| M0 multinomial | −1074 | −1009 |
| M1 Dirichlet-multinomial | −65.3 ± 1.0 | 0 |
| **M3 logistic-normal (λ = 0.05)** | **−58.0 ± 0.9** | **+7.3 ± 0.3 (better for 91 % of samples)** |

- **M3 is the best model.** It allows each taxon its own variance and correlations between taxa; the DM forces one common
  overdispersion (ρ = 0.172, 95 % CI 0.157–0.185, i.e. variance × 173), whereas the data range from × 34 to × 821 across categories.
- **Covariates (M2) do not improve prediction.** Age, sex and navel type are significant in-sample (likelihood-ratio test p < 10⁻⁴,
  AIC prefers M2), but BIC prefers M1 and cross-validation shows no gain (+0.04 ± 0.06 nats per sample); adding wash frequency
  (n = 132) makes it slightly worse. The effects are real but small compared with the differences between people.

**Phase 3 – validation** (`data/processed/valid_*.csv`, 200 simulated datasets per model):

- **M3 is the most realistic simulator.** It reproduces 4 of 9 summary statistics inside its 95 % parametric band (M1: 0, M0: 0),
  including mean Shannon, mean Simpson and the dominance of the top taxon. Real and M3-simulated samples are almost
  indistinguishable by PERMANOVA (median R² 0.001–0.002), while M1 is clearly separable on Bray–Curtis (R² 0.014, always significant).
- **M3 produces too few zeros**: 32 % zeros vs 41 % in the real data, so taxa appear in too many samples. The Dirichlet-multinomial
  gets the zeros right but makes samples far too similar to each other.
- Removing the 7 samples with < 80 % assigned reads changes nothing (CV gain of M3 over M1: 7.1 vs 7.3 nats per sample).
- **M4 = M3 + zero inflation** (each taxon structurally absent from a person with probability πⱼ, 0.006–0.52, calibrated by
  method of moments) fixes the zeros and improves several checks (variance, dispersion, Bray–Curtis distribution). By a decision
  rule fixed before the comparison, M3 nevertheless stays the **primary simulator** (tie on the independent statistics; M4's
  Aitchison PERMANOVA R² is slightly larger, 0.0020 vs 0.0008). **Both M3 and M4 are used in the power study**, M4 as sensitivity analysis.

**Phase 4 – seasonal power study** (`data/processed/power_*.csv`; 145 scenarios × 1000 simulated studies; plan frozen beforehand):

- **The tests are valid:** with no seasonal effect they reject 3.5–6.3 % of the time (target 5 %), and a negative control with
  shuffled month labels gives 3.2–5.4 %.
- **Minimum detectable effect at 80 % power** (amplitude A of the log-ratio; peak-to-trough fold change e^{2A}):

  | n | cosinor on CLR + BH | PERMANOVA Aitchison | PERMANOVA Bray–Curtis |
  |---|---|---|---|
  | 96 | A = 1.20 (×11) | not reached | not reached |
  | 192 | 0.80 (×5) | 1.33 (×14) | not reached |
  | **288 (≈ real study)** | **0.66 (×3.8)** | 1.05 (×8) | not reached |
  | 384 | 0.57 (×3.1) | 0.92 (×6) | not reached |

- **Per-taxon cosinor regression is the most powerful tool**, Bray–Curtis PERMANOVA the weakest. A study the size of ours
  could only detect seasonal changes of roughly a fourfold peak-to-trough swing in a few taxa.
- More affected taxa or less between-person variation raise power; more sequencing depth barely helps (between-person variation
  dominates); with zero inflation (M4) the detectable effect is about 20 % larger.
- Benjamini–Hochberg keeps the false discovery rate near 5 %; it rises slightly (to 7 %) for large effects because of
  compositional closure.

## Conventions

- **One global seed** (`src/config.py`); child generators are derived from it, no other seeds.
- Matrices are **samples × taxa** in all code; counts are out of N = 1000 reads.
- Deliberate shortcuts are marked in code with `# simplification:`.
- Figures use `src/plotstyle.py` (labelled axes, colour-blind-safe palette) and are saved to `figures/`.
- No imputation of missing covariates: models use complete cases and always report *n*.
- Exploratory p-values are corrected with Benjamini–Hochberg and labelled exploratory.
- Every figure and number in the report must be generated by code in this repository.

## Limitations

- The seasonal signal is **simulated**; nothing here estimates real seasonality.
- **Cross-sectional, single cohort:** one sample per subject; months are assigned at random in the simulation.
- **Rarefied data:** the table was cut to 1000 reads per sample, which discards information (McMurdie & Holmes 2014).
- **Missing mass and unresolved taxa:** the `Unassigned` category and bins such as "Staphylococcaceae (unresolved below family)"
  are bookkeeping devices, not single biological taxa.
- **Covariate missingness is not random** (`Wash_Freq` missing in 42.5 %), so models using it describe a subset of subjects.
- Provenance of the dataset relative to the published study is **unverified**.

## Glossary

| Term | Meaning |
|---|---|
| **Compositional data** | data where only ratios between parts are informative (each sample is divided by its total) |
| **Rarefaction** | randomly subsampling every sample to the same number of reads (here 1000) |
| **Prevalence** | share of samples in which a taxon has at least one read |
| **Overdispersion** | variance larger than a multinomial/binomial model predicts |
| **Taylor's law** | variance ≈ *a* · mean^*b*; the slope *b* on log–log axes describes the mean–variance relationship |
| **Multinomial / Dirichlet-multinomial** | count models with fixed probabilities / with probabilities that vary between samples |
| **Logistic-normal** | Gaussian distribution on log-ratios, mapped back to proportions |
| **CLR / ALR** | centred / additive log-ratio transforms that move compositions to ordinary Euclidean space |
| **Aitchison distance** | Euclidean distance between CLR vectors |
| **Bray–Curtis** | dissimilarity based on shared abundance, bounded in [0, 1] |
| **PCoA** | principal coordinates analysis: a 2-D map of samples from a distance matrix |
| **PERMANOVA** | permutation test of whether groups differ in a distance matrix |
| **Cosinor regression** | regression on cos and sin of the time of year to detect a seasonal cycle |
| **FDR / Benjamini–Hochberg** | control of the expected share of false discoveries among rejections |
| **Type I error / power** | false-positive rate under no effect / probability of detecting a true effect |
| **Monte Carlo standard error** | uncertainty of a simulated estimate, √(p(1−p)/R) for a rejection rate from R replicates |
